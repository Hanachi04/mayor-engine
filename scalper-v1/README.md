# Futures Scalper v1

هذا مجلد مستقل لسكالبير Binance USDT-M Perpetual Futures. لا يعتمد على ملفات MaYor v3 ولا يعدّلها، ولا ينفّذ أوامر تداول حقيقية؛ وظيفة `scan.js` هي قراءة السوق وإرسال إشعار Telegram اختياريًا وتسجيل الإشارة.

## الضبط المحسوم

| البند | القيمة |
|---|---|
| التنفيذ | 1m |
| التأكيد | 3m و5m |
| الاتجاه | 15m |
| الاتجاهات | LONG وSHORT |
| Cooldown | 3 دقائق |
| الحد اليومي | 30 إشارة |
| أقصى احتفاظ | 20 دقيقة، مطبّق داخل حلقة الخروج |
| الرموز الأولية | BTCUSDT وETHUSDT وSOLUSDT وBNBUSDT وXRPUSDT |
| الباكتيست الأول | شهر واحد من بيانات 1m محلية، مع فصل IS/OOS |
| التركّز | رفض النتيجة إذا تجاوزت مساهمة أعلى 3 صفقات 50% من الصافي |

## التشغيل

يُنَفّذ الباكتيست محليًا فقط عبر `node scalper-v1/backtest.js`. لا يوجد Workflow Actions لهذا الاختبار الأول. يمكن تنزيل البيانات العامة مرة واحدة إلى `fixtures/` عبر `node scalper-v1/fetch-data.js`، وبعد ذلك يعمل الباكتيست دون اتصال شبكي.

التشغيل الحي، عند اعتماده لاحقًا، يكون عبر `node scalper-v1/scan.js` كل 15 دقيقة بواسطة جدولة خارجية. يجب توفير `TELEGRAM_TOKEN` و`TELEGRAM_CHAT`، ولا توجد أي دوال فتح أو تعديل أو إغلاق أوامر.

كل تقييم يستخدم نافذة إحماء ثابتة لا تتجاوز 1500 شمعة، ولا يقرأ شموعًا بعد وقت التقييم. كما أن حد الاحتفاظ يُتحقق منه برمجيًا ويُفشل الباكتيست إذا تجاوز 20 دقيقة.

## التحقق

شغّل `node scalper-v1/test/unit.test.js` للتحقق من بوابة الشموع غير المكتملة، position sizing، cooldown، حد الاحتفاظ، وفحص التركّز. لا تُفسّر نتائج الباكتيست الأول كحكم نهائي قبل مراجعة جودة البيانات، حجم العينة، وفحص التركّز.
