# طبقة التعلم — Shadow ML

## الهدف
تحسين **تصفية** الإشارات تدريجياً دون إعادة ضبط أوزان المؤشرات يومياً.

## الوضع الافتراضي: `log`
- يحسب `P(win)` من نموذج لوجستي مدرّب على `tracked.json`
- يكتب `data/ml/shadow_log.jsonl`
- **لا يمنع** البث

## تفعيل التصفية لاحقاً فقط
```bash
ML_SHADOW_MODE=filter
ML_MIN_PWIN=0.55   # اختياري
```
لا تفعّل `filter` قبل أسابيع من تطابق قرارات الظل مع نتائج حقيقية.

## إعادة التدريب
```bash
node engine/ml/train_shadow.js
```
ينتج `data/ml/shadow_model.json` مع تقسيم زمني 70/30.

## قواعد إضافية من البيانات
- `BLOCK_UTC_HOURS=18` — تخطي بث جديد في ساعات UTC ضعيفة في العينة الحالية (قابل للتعطيل بتفريغ المتغير).

## تحذير
دقة النموذج على العينة الحالية محدودة. التحسين الحقيقي = تصفية + طبقة A + عينة أطول، وليس ضمان رفع Win Rate.
