# طبقة التكيف الآمن (A)

لا تغيّر أوزان المؤشرات ولا `STRATEGY_MODE`. تمسّ **التعرض فقط**.

## الآليات
1. **قائمة سوداء رموز** من آخر N صفقة مغلقة (افتراضي 8، حد أدنى 6)
   - حظر 72 ساعة إذا `PF < 0.85` أو صافي النافذة `≤ -3%`
   - حد أقصى 3 حظرات جديدة لكل دورة
2. **قواطع** (في workflow): خسارة يومية 4% أو 4 خسائر متتالية → إيقاف إشارات جديدة لليوم

## ملفات
- `data/adaptation_state.json` — الحظر الحالي
- `data/adaptation_log.jsonl` — سجل القرارات
- `engine/adaptation.js` — المنطق

## تعطيل
`ADAPTATION_ENABLED=0` في بيئة التشغيل.
